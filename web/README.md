# velle.ru на Next.js

Основной сайт velle.ru (раньше WordPress), перенесённый на Next.js 16 с той же вёрсткой и контентом.
Источник — копия сайта из Web Archive в `../site`.

```bash
npm install
npm run build   # статический сайт в out/
npm run dev     # разработка на http://localhost:3100
```

`out/` можно выложить на любой статический хостинг: адреса те же, что у WordPress (`/products/ovsyanoe/`).
Для несуществующих адресов хостинг должен отдавать `out/404.html` с кодом 404 — Netlify, Vercel,
Cloudflare Pages и GitHub Pages делают это сами, в nginx нужна строка `error_page 404 /404.html;`.
Локально так же работает `npm start` (`scripts/serve.py`).

## Как устроено

- `content/*.json` — товары, рецепты, статьи блога и метаданные страниц. Получены из копии командой
  `npm run extract` (`scripts/extract.py`); дальше их можно править вручную.
- Тяжёлые PNG/JPEG из архива отдаются как WebP: `python3 -I scripts/optimize_images.py` делает копии
  (до 2000px, ≈10× легче), маленькие картинки для меню шапки и меняет ссылки в исходниках. Оригиналы
  остаются на месте. Запускать заново после `npm run extract` и после добавления картинок.
- `app/` — страницы. Каталог, товары, рецепты и блог строятся из JSON.
- `components/generated/` — шапка-подвал, всплывающие окна и уникальные страницы (главная, «О компании»,
  контакты, «Где купить», «Устойчивое развитие»), сгенерированные из HTML копии `scripts/html2jsx.py`.
  После генерации это обычные компоненты, их можно редактировать.
- `public/wp-content/` — CSS темы, картинки и шрифты по прежним путям, поэтому `url(...)` в CSS работают.
- `components/ThemeScripts.tsx` — порт jQuery-скриптов темы: слайдеры Swiper, формы, аккордеоны, видеоплеер.
  `components/Catalog.tsx` и `components/FilteredList.tsx` — фильтры каталога, рецептов и блога.

## Что работает иначе, чем в WordPress

- **Формы** (обратная связь, бесплатный образец) отправлялись в `admin-ajax.php`. Теперь они шлют те же поля
  на адрес из `NEXT_PUBLIC_FORMS_ENDPOINT`; пока он не задан, форма сообщает, что отправка не подключена.
  reCAPTCHA не подключена.
- **Фильтры и «Загрузить»** в рецептах и блоге работают в браузере (`?meal=`, `?time=`, `?blog-mark=`, `?page=`).
- **Поиск** (`/search/?search=`) ищет по названиям товаров, рецептов и статей.
- **Категории статей блога** («Бариста» / «Вместо молока») в копии не размечены, они проставлены по ключевым
  словам — проверьте поле `category` в `content/blog.json`.

## Чего нет в Web Archive

Около 200 файлов, на которые ссылаются страницы, архив не сохранил: логотипы магазинов на «Где купить»,
две картинки баннеров на главной, часть старых фото рецептов. Их нужно взять с сервера velle.ru.
